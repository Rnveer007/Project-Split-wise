How Split keeps things private

Each group has a secret code inside its invite link. Everything you add is encrypted on your phone with that code before it's sent, so the server only stores scrambled data that nobody can read, not even the server owner.

Only people who have the invite link can see or add to the group, so share it only with group members.

Split is free, with no ads, no accounts and no tracking. It works offline too: changes are saved on your phone and sync when you're back online.
